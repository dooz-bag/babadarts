PHOTOS FROM PAST LEAGUES AND TOURNAMENTS
========================================

Put photos in this folder, then list them in data/archive.js under the season
they belong to.

Example — in data/archive.js:

    photos: [
      { src: "assets/img/archive/2024-autumn-final.jpg", caption: "The final." }
    ]

...means you need a file in this folder called:

    2024-autumn-final.jpg

Until that file exists, the website shows a friendly neon placeholder with the
missing file name written on it, so you always know exactly what to add.

NAMING SUGGESTION
Start every file with the season id so they stay tidy, e.g.
  2024-autumn-final.jpg
  2024-autumn-trophy.jpg
  2024-hub-cup-winners.jpg
