PHOTOS OF THE BAR
=================

Drop your photos in THIS folder using exactly these file names and they will
appear on the home page automatically:

  board.jpg         - the dartboard / machines
  bar.jpg           - the bar itself
  league-night.jpg  - a busy league night

Until you add them, the home page shows a neon placeholder telling you which
file is missing. Nothing breaks.

TIPS
- Landscape photos look best (roughly 4:3).
- Keep them under about 400KB each so the site stays quick. Any free online
  "image compressor" will do this for you.
- .jpg, .jpeg, .png and .webp all work, but if you use a different extension
  you must also change the file name in assets/js/pages.js (search for
  "hub-photos").
