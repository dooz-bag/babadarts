PLAYER PHOTOS (completely optional)
==================================

If you don't add anything here, every player gets a neon badge with their
initials on it. That looks perfectly good, so feel free to ignore this folder.

To use a real photo:

1. Put a square-ish photo in this folder, e.g.  yuki.jpg
2. In data/players.js, set that player's avatar, e.g.

     { id: "yuki", ... avatar: "assets/img/players/yuki.jpg", ... }

Square crops work best (they're displayed as circles). If the file is missing
or misspelled, the site quietly falls back to the initials badge.
